# 시드 DB 출처

`welding_standards.csv`(표준 용접 기준)와 `workspaces/demo/symbol_dictionary.json`(demo 문자/기호 사전)의 근거입니다.
조립 트리(`assembly_tree.csv`)와 데모 작업(`jobs.json`)은 화면 시연용으로 지어낸 값이라 여기서 다루지 않습니다.

> **주의 — 조선소 승인 WPS가 아닙니다.** 아래 용접 조건은 제조사가 공개한 **참고 조건**이고, 출처 문서도
> "참고값이며 결과를 보증하지 않는다"고 적고 있습니다. 실제 로봇 용접에는 해당 조선소·선급이 승인한 WPS 값으로 바꿔야 합니다.

## 표준 용접 기준 (`welding_standards.csv`)

**출처: 다이도 특수강(大同特殊鋼) 용접재료 기술자료 「溶接施工」 ③ 溶接条件参考表 (1) CO2溶接**
<https://www.daido.co.jp/products/weld/shiryo/ds/05.pdf>

- 같은 자료의 적정 전류·전압 그래프가 DS1·DS60 등 **솔리드 와이어** 기준이라 공정은 `GMAW`(CO2 가스 솔리드 와이어)로 적음
- 자세는 AWS 표기: `1F` 아래보기 필렛, `2F` 수평 필렛, `1G` 아래보기 맞대기 (용어사전 STD-0208 아래보기자세 PA, STD-0214 수평수직필릿 PB)
- 자료가 판 두께별 값이라 `thickness_min_mm = thickness_max_mm`(그 두께에만 해당). 사이 두께는 지어내지 않음 → 맞는 행이 없으면 2단계가 `standard_conflict`로 작업자 확인
- 각장(`leg_min_mm`·`leg_max_mm`)도 출처 표 값 그대로. PAC 손글씨처럼 판 두께 없이 각장만 있으면 2단계가 각장으로 행을 고름 —
  사이 각장(5.5mm)은 가장 가까운 각장 행을 쓰고 `standard_matched: false` + `standard_conflict`(warning)로 작업자 확인
- 와이어 지름은 기준표 형식(`backend/app/schemas.py` `WeldingStandard`)에 칸이 없어서 아래에만 적음

**한 판 두께에 출처 행이 여러 개일 때 고른 규칙:** 와이어 1.2mm 우선, 그다음 각장이 판 두께에 가장 가까운 행.
버린 행: 표 5·7 6mm(각장 4~4.5 · 1.2mm, 각장 6~7 · 1.6mm), 8mm(각장 8~9 · 1.6mm), 12mm(각장 10 · 1.6mm) / 표 5·3 6mm(루트 간격 1.2~1.5).

**3F(수직 필렛)는 상진(표 5·12)을 넣음:** 선체 구조 필렛은 용입이 깊은 상진이 일반적이고, 하진(표 5·10)은 얇은 판에 씀.
`F` = "3F 용접장 각장"이 상진·하진 중 무엇인지는 과제 안내에 없어(운영측도 확인 안 됨) 하진 자료는 아래에만 둠.
기준표의 `position`은 AWS 자세(`3F`)만 적고 상진·하진은 구분하지 않음.

## demo 문자/기호 사전 (`workspaces/demo/symbol_dictionary.json`)

| 항목 | 근거 |
| --- | --- |
| `F` · `V` · `S` (수기 각장) | PAC 과제 안내 (루트 README "셀 형태와 각장") |
| `slit` · `slot` · `collar_front` · `collar_back` · `scallop` (셀 형태 기호) | PAC 과제 안내. code는 `backend/app/schemas.py`의 `CellFeature`와 같음 (1단계 기호 인식의 label). 뜻은 용어사전 STD-0206 스캘럽 · STD-0131 슬롯이음 · PRC-0083 스캘럽(쥐구멍·마우스홀) |
| 공정 `FCAW` · `GMAW` · `SMAW` · `SAW` · `EGW`, 용입 `CJP` · `PJP`, 자세 `PA` · `PB` · `PF` · `PG`, 검사 `VT` · `UT` · `RT` · `MT` · `PT`, 현장 약어 `BKT` · `E/J` · `G/B` | 「선박용접 용어사전 DB」(표준·사전 용어 622개, 현장·실무 용어 228개, AWS A3.0 · ISO 등 근거). 뜻 끝에 용어사전 ID를 적음 |
| `FW` · `BV` · `▲` | **근거 없음 — 처음부터 있던 데모 값.** shared 예시와 테스트가 쓰고 있어 남겨 둠. 용어사전에서 `FW`는 플래시버트용접(STD-0073)이라 실제 사전을 만들 때 다시 확인해야 함. |

## yeongam 문자/기호 사전 (`workspaces/yeongam/symbol_dictionary.json`)

`demo` 사전을 그대로 복사하고 `FW` 하나만 용어사전 뜻(플래시버트용접, STD-0073)으로 바꿨습니다. "같은 기호라도 현장(워크스페이스)마다 뜻이 다르다"는 시연용 예이며,
두 워크스페이스의 도크 이름(울산 1도크 · 영암 2도크)도 시연용 가정입니다.
